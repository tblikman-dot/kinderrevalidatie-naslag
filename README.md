# Naslag Kinderrevalidatie

Persoonlijk naslagwerk voor kinderrevalidatie: een overzicht van aandachtsgebieden met eigen
aantekeningen en snelle links naar de Richtlijnendatabase.

## Belangrijk

- **Publiek maar onvindbaar**: deze site staat live op GitHub Pages, maar wordt nergens
  gelinkt en heeft `robots.txt` + `noindex` om te voorkomen dat hij in zoekmachines verschijnt.
  Iedereen met de exacte URL kan de site *bekijken*.
- **Geen patiëntgegevens.** Dit is bedoeld als naslagwerk met algemene aandachtsgebieden en
  richtlijnen, niet voor namen, dossiers of individuele patiëntinformatie.
- **Aantekeningen worden lokaal opgeslagen** (`localStorage`) — alleen op het apparaat/de
  browser waarin je ze intypt. Ze synchroniseren niet automatisch tussen apparaten of met
  collega's.

## Sync tussen apparaten/collega's toevoegen

Als je dit later wilt delen met collega's of tussen je eigen apparaten wilt synchroniseren,
kan dat door een Firebase Realtime Database (of vergelijkbare dienst) te koppelen — geef dan
een projectconfiguratie door.

## Structuur aanpassen

De aandachtsgebieden in de linkerkolom zijn een voorgestelde indeling — voeg zelf gebieden toe
met de ＋ knop, of verwijder ze met het prullenbak-icoon in de detailweergave.
